0.1 Prerequisites & Group Registration via Portal

Any allied unit, regiment, or division can be onboarded into the Cortex Command Network as an independent, isolated sector. Every sector maintains its own database partition, custom roles, activity check cycles, points, and Discord notifications.

1. Roblox Group Admin
You must be the Owner or an Administrator with rank configuration authority in the Roblox group you wish to register.
2. Discord Server Authority
You must have Manage Server permissions in your Discord guild to invite the Cortex bot and copy channel IDs.
3. Bot Account
A secondary Roblox account dedicated as the rank-changer bot with its .ROBLOSECURITY cookie extracted.
How to Register via the Portal:
  1. Log in with your Roblox account via Roblox OAuth.
  2. Navigate to the Group Selection Portal (/portal/select-group).
  3. Click the + Register New Sector button in the top right.
  4. Enter your Roblox Group ID (from your group's Roblox URL: roblox.com/groups/{GROUP_ID}) and your preferred Sector Display Name.
  5. Submit the form. Cortex immediately validates the group on Roblox, maps the ranks, and creates your sector console partition!

0.2 The 8-Step Sector Configuration Checklist

Once registered, the unit High Command must complete the following configuration steps in Sector Settings before opening member activity tracking:

Sector Identity & Display Name Step 1
Customize your sector's official call sign, full unit name, and tactical mission description displayed in the navbar and bot embeds.
Visual Theme Palette Selection Step 2
Select from 8 distinctive visual aesthetics (Neon Purple, Clean Light, Slate Charcoal, Deep Graphite, Tactical Steel, Cyberpunk Grid, Combat Crimson, SpecOps Emerald). All members accessing your console inherit your chosen theme.
Discord Server ID & Dynamic Channel Routing Step 3
Input your Discord Server (Guild) ID so Cortex routes commands to your sector. Configure the 3 dedicated channel fields:
  • 📢 Webhook Notifications Channel ID: Mandatory for sync summaries, promotion broadcasts, and system alerts.
  • 📊 Activity Logging Channel ID: Optional restriction for @Cortex log ... commands.
  • 📋 Rank Changes Channel ID: Optional restriction for @Cortex promote ... commands.
Roblox Bot Cookie Configuration (.ROBLOSECURITY) Step 4
Extract and save the .ROBLOSECURITY cookie from a secondary bot account. This enables Cortex to automatically promote operatives on the Roblox website when staff issues promotion commands. (See Section 3.3 for the complete extraction walkthrough).
Granular Rank Permissions Matrix Step 5
Navigate to the matrix table in Sector Settings. For each Roblox rank in your group, configure who can promote, log activity, delete entries, view roster data, manage AC, or hold master HCT authority.
Dynamic Activity Types & Point Values Step 6
Define the operations your unit performs (e.g. Patrol = 1.0 pt, Combat Training = 1.0 pt, Raid = 2.0 pts, Tryout = 1.0 pt). Mark limited activities (max credit per cycle) as needed.
Rank Quota Benchmarks Step 7
Set the required operational points expected per rank for each activity check cycle (e.g., Operative = 2.0 pts, Officer = 4.0 pts, Commander = 6.0 pts).
Create Initial Activity Check (AC) Cycle Step 8
Under AC Management, create your first operational cycle. Set the start date, end date, and quota cycle name. Cortex automatically tracks member progress against the active period!

3.3 Extracting & Configuring the Roblox Bot Cookie (.ROBLOSECURITY)

To allow Cortex to perform automated roster promotions and live Roblox synchronization on behalf of your sector, you must configure a Roblox Automation Cookie. Follow this step-by-step guide carefully:

CRITICAL SECURITY RULE: Create a Dedicated Bot Account!
NEVER use your personal main account! Create a brand-new, secondary Roblox account (e.g. YourGroup_CommandBot). Add this account to your Roblox group and grant it a role with "Change Member Rank" permission.
Step-by-Step Cookie Extraction:
Open an Incognito / Private Browser Window
Open an Incognito or Private browsing window in Google Chrome, Microsoft Edge, or Mozilla Firefox. (Using Incognito prevents interference with your personal account sessions).
Log In to the Dedicated Bot Account
Navigate to roblox.com and sign in with the bot account's username and password. Complete any 2-step verification if prompted.
Open Developer Tools (Inspect Element)
Press F12 or Ctrl + Shift + I (Mac: Cmd + Option + I), or right-click anywhere on the webpage and select Inspect.
Navigate to Storage / Application Cookies
In the DevTools top navigation tabs, select Application (Chrome/Edge) or Storage (Firefox). In the left panel, expand Cookies and click on https://www.roblox.com. (Alternative via Network tab: Select the Network tab, reload the page, click on any request to roblox.com, and look under Request Headers -> Cookie).
Locate and Copy the .ROBLOSECURITY Value
Find the cookie named .ROBLOSECURITY in the table. Double-click its Value field, select all (Ctrl + A), and copy it (Ctrl + C). The string begins with _|WARNING:-DO-NOT-SHARE-THIS.--.... Make sure to copy the entire string without leading or trailing spaces.
GOLDEN RULE: DO NOT CLICK "LOG OUT" ON ROBLOX!
CRITICAL: If you click the "Log Out" button on the Roblox website, Roblox will immediately invalidate the session token on their authentication servers, rendering the cookie dead! Simply close the incognito browser window without logging out.
Paste and Save in Sector Settings
Go to Sector Settings , paste the string into the Roblox Bot Cookie field, and click Update Roblox Cookie. Cortex verifies the cookie against the Roblox API immediately!

3.5 Managing Activity Cycles (AC) & Closeout Protocols

Activity Check cycles define operational reporting periods (typically bi-weekly or monthly). Under AC Management:

  • Open Period: Set cycle title (e.g. October Operations Cycle 2) and establish exact start and end dates.
  • Exemptions: HCT can flag operatives as LOA (Leave of Absence) or Exempt to preserve their standing during active cycles.
  • Cycle Closeout: When the cycle concludes, click Closeout Cycle. Cortex archives final point counts, flags passing/failing members, generates the historical report, and resets cycle points for the next period.

3.6 Dynamic Activity Types & Rank Quota Configuration

Every sector can establish custom operational activities. If your unit hosts specialized operations like Outpost Patrols, Joint Naval Exercises, or Scout Missions, you can add them with custom point multipliers.
