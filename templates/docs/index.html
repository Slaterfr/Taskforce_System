3.2 Granular Rank Permissions Matrix

HCT possesses total control over which ranks can execute platform actions. In Sector Settings, toggle checkboxes per role:

  • Can Promote: Permits role holders to update member ranks in DB and Roblox.
  • Can Log Activity: Permits role holders to log trainings, raids, and events.
  • Can Delete Activity: Permits redacting mistakenly submitted logs.
  • Can View Data: Grants access to internal statistics and member progress.
  • Can Manage AC: Allows modifying cycle dates, quotas, and granting exemptions.

3.3 Automation Bot Security (.ROBLOSECURITY Cookie)

Each sector can link its own dedicated Roblox automation account. The system validates the cookie live with Roblox APIs upon saving and displays the bot's username and ID.
